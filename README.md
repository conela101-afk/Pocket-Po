# Pocket Po

Pocket Po is a private, offline regulation companion. Po, a pixel orange cat, keeps you company while you try short, gentle tools for hard moments and calmer ones.

It is built to ask as little of you as possible. There are no streaks, no reminders, no scores and nothing to catch up on. Po is always fine.

## What's in it

- **Now:** one tap to a small set of pre-chosen tools, with no menus and no questions.
- **Build:** short practices for calmer moments, if you like.
- **Library:** breathing, body, grounding, absorbing and thinking tools to browse.
- **More:** settings, safety information and, in time, notes and an optional export.

Pocket Po is a work in progress. Some tools are placeholders for now.

## Install it to your home screen

Pocket Po is a web app. Once it has loaded, it works with no connection.

**iPhone or iPad (Safari)**
1. Open the app's web address in Safari.
2. Tap the Share button.
3. Tap **Add to Home Screen**, then **Add**.

**Android (Chrome)**
1. Open the app's web address in Chrome.
2. Tap the menu (three dots).
3. Tap **Install app** or **Add to Home screen**.

Open it once with a connection first, so it can save itself for offline use. After that, a long-press on the home screen icon offers a **Now** shortcut on most Android phones.

## Your data stays on your device

- Everything you do in the app is stored only on your phone.
- There are no accounts, no analytics, no adverts and no third-party scripts.
- The app makes no network calls other than loading its own files.
- Nothing is sent anywhere unless you choose to share or export something yourself.
- Clearing your browser's site data or removing the app will delete what it stores.

## Important: what this is and isn't

Pocket Po is a self-help tool. It is **not** medical advice, and it is **not** a substitute for professional care or treatment. It does not diagnose, monitor or treat any condition, and it does not read or interpret anything you write.

Pocket Po is **not** a crisis service. No one is watching the app, and it cannot call for help for you.

If you're in crisis or need someone now: Samaritans 116 123 (free, 24/7) · Pieta 1800 247 247 · Emergency 999 or 112

These are Irish and UK services. If you're somewhere else, please use your local emergency number.

Some tools involve cool water on the face. Please read the safety note in the app before you try them, and skip anything that doesn't feel right. If you're unsure, check with your GP.

## For developers

Plain HTML, CSS and JavaScript. There is no framework and no build step.

```
npm run serve   # local server at http://localhost:8080
npm run check   # consistency and safety checks
```

Read `SPEC.md` for the build spec and `CLAUDE.md` for the design rules. Decisions are recorded in `DECISIONS.md`.

Please don't add personal data to this repository, including in issues, screenshots or test data. Use obviously fake data.
